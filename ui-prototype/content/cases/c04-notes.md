# 《配阴婚》背后的档案

> SignaPilot · Case Notes 04
> 定稿，2026 年 11 月 12 日经 PO 批准封存。含剧透。

## 一、冥婚是什么，各地并不一样

冥婚，也叫阴婚、配阴亲、配骨，是给已经去世的人办的婚事。它不是一种统一的习俗，也不等于犯罪：历史上和今天，大量冥婚是两家自愿说合、或者只用替代物完成的，与盗掘、买卖和杀人无关。小说写的是其中最坏的一种情形。

**很古老，也一直有人反对。** 《周礼》里已有“禁迁葬者与嫁殇者”的话，说明当时有这种做法，也说明官方并不赞成。史书里常被提到的例子是曹操为早夭的儿子曹冲聘亡女合葬。［待核：转引自黄景春的文章，未核对原典］

**形式有好几种。** 人类学和民俗学的记录里至少有这些：

- 两个都已去世的未婚男女，由两家说合，把遗骨合葬。
- 一方去世，另一方在世（如已订婚的女子“抱着牌位成亲”，或男子“娶鬼妻”）。
- 不用遗体，只用替代物：牌位、纸扎的人、白公鸡。［已核：Tan 2020 转述二十世纪中叶新加坡华人的记录］

**替代物在当代北方同样存在。** 《南方周末》2021 年的调查报道里，受访者说没钱的人家“弄一块砖，写上名字用衣服包一包”也算配了。［已核］黄景春和贾玉洁对山西阳泉的调查把当地冥婚归为两类：死者与死者，死者与人偶。［待核：只见到论文摘要］小说里二婶说的纸人、祁晓云说的砖头，以及结尾那块青砖，根据在这里。

这一点对理解小说很要紧：按习俗本身，一具真实的遗体从来不是唯一的办法。

## 二、小说的地方和它的社会背景

故事放在晋西的山村。选山西，是因为研究和报道都指向这里。

**集中在华北。** 民俗学者黄景春从 2003 年起在山西、陕北、河北、山东等地调查冥婚，他的判断是：冥婚引发恶性案件最多的地方，就是这一习俗最盛行的山西和陕北。［已核：见其 2021 年文章及《南方周末》报道的转述］犯罪学者 T. Wing Lo 的研究也指出，被贩卖的遗体主要是女性，多来自较贫困的省份。［待核：只读到摘要］

**为什么“不配不行”。** 黄景春归纳了三个原因：父母的情感需要，宗法家族制度的要求，对死者作祟的恐惧。他的受访者常说的一句话是“不配不行”。［已核］Lo 的摘要里写到，未婚而死的人不得与祖先葬在一起，家人担心其孤单。小说里“进不了祖坟”“孤坟”的压力由此而来；“孤坟”这个叫法是小说的用词。未婚者不入祖坟并不是全国各地共有的规矩，同一个地区里各个家族的做法也不一样，所以正文写的是“在这个村里”。

**谁来说合。** 报道里出现的牵线人有风水先生和专门的中介。［已核］小说把看日子的先生和媒人写成同一个人，是为了情节：定日子的人同时也是供货的人。

**一天之内，先喜后丧。** 人类学者 Chris K. K. Tan 的助手 2016 年在河北广宗县记录过一场 2010 年的冥婚：女方去世两天后说定，三天后办事；新娘装在苫着红布的棺材里送到；摆喜宴，随后下葬；只有近亲参加。［已核］小说里红布棺材、喜馍、当天下葬的安排参照了这段描述，但广宗在河北，不是山西。

**不是全村人都信，也不是信的人都一样。** 学者顾春军在河北宣化的调查认为，今天人们办冥婚更多是求情感上的安慰，对鬼祟的恐惧已经很淡。［已核：《南方周末》转述］小说里有捏着喜馍说“还不是活人心里图个踏实”的二婶，有说“哪一样都不该办”的大学生，也有把折子拿出来的母亲。

## 三、文书、名字和亲属关系

**小说里的“婚书”是虚构的。** 这次读到的当代田野材料都没有描写冥婚中使用的书面婚约。那张红纸的格式、“乾造”“坤造”的写法、死期留一格后填、当众念一遍就算“礼成”，都是本篇的设计，不是山西或任何地方冥婚的通行样式。“乾造”“坤造”借自排八字时对男女命造的称呼。

正文也是这样交代的：帖子怎么写是周守义“自己的一套，出了这道沟，别处未必是这个写法”；“新人的脸不兴细看”是他嘴里的“咱这一带”的规矩，祁晓云当场说她没有听过。

**为什么要给它一张纸。** 虚构这张婚书，是因为冥婚真正在做的事可以用它说清楚：把一个死去的人写进一套亲属关系。写上去以后，她有了丈夫的姓，有了婆家，有人在清明叫她媳妇、嫂子。Tan 记录的广宗案例里，两家此后以亲家相待；《南方周末》记录的山东梁山案例里，男方还会过继一个孩子给这对“夫妻”，两家的关系“比一般的亲家关系还要好”。［已核］

**纸上有几格，就只认几格。** 小说里那张婚书需要填的是姓名、生年、死期。它不问这个人是怎么死的、有没有孩子、愿不愿意。祁晓云在第五章末尾想到的就是这个：纸上没有写的，就当它没有。

**一张空着的格子。** 全篇的悬念压在“死期”那一格上：腊月初五写婚书时它空着，8 天后被填上。这个设计完全是虚构的，没有对应的田野记录或案件。

## 四、遗体买卖与相关犯罪

需求一旦变成价格，就有人去供货。下面是有案可查的几类情形，都来自研究和公开报道。

**盗掘。** 2014 年山东有 11 人因盗掘一具女性遗体并出售被抓；这具遗体后来以数万元的价格卖给河北的一户人家。［已核：Tan 2020 引当年报道］

**价格。** 各种来源给出的数字差别很大，从几千元的象征性彩礼，到 2015 年河北一例的 7 万元；2018 年河北邢台一起案件中，法院查明的售价在 4 万到 6.8 万元之间。［已核：前者见 Tan 2020，后者见《南方周末》］小说里的 18 万和 3 万是虚构的数字，量级参照了这些报道。

**杀人。** 最极端的是为了卖遗体而杀人。甘肃的马崇华以介绍对象为名接近被害人，将其杀害后把遗体运往陕北出售；庆阳市中级人民法院 2019 年以故意杀人罪判处其死刑，2021 年 2 月执行。［已核：新京报引法院通报］Tan 还提到 2016 年的另一起案件：一名女性被人用了镇静药物，险些被活着下葬。［已核：Tan 2020 引当年报道］

这两起真实案件的被害人都是有智力或精神障碍的女性。小说没有照搬这一点。写一个有工作、有孩子、识字记账的女人，是不想让读者以为只有某一类人才会成为被害人；她出事，是因为她缺钱，身边没有会马上找她的人。

第三章里护士先摸脉搏、看瞳孔的那一段，来自上面那起“险些活埋”的报道。

**一条必须说明的学术更正。** 2023 年《Religions》第 14 卷第 6 期有一篇分析 260 份涉冥婚裁判文书的论文（Zhou 与 Feng）。该文已于 2026 年被期刊正式撤稿，[撤稿公告](https://doi.org/10.3390/rel17080873)。本篇没有采用其中任何数据或结论，读者在别处见到“法院对冥婚的三种态度”“260 个案例”一类说法时，也请留意它的出处。

## 五、法律的边界

小说只写到报案和侦查，没有写任何判决。下面是相关的条文，都核对过原文。

- **《刑法》第三百零二条**：盗窃、侮辱、故意毁坏尸体、尸骨、骨灰的，处三年以下有期徒刑、拘役或者管制。［已核］
- **《刑法》第二百三十二条**：故意杀人的，处死刑、无期徒刑或者十年以上有期徒刑；情节较轻的，处三年以上十年以下有期徒刑。［已核］
- **《民法典》第一千零七条**：禁止以任何形式买卖人体细胞、人体组织、人体器官、遗体；违反规定的买卖行为无效。［已核］

要注意三点。

第一，不同的人做的是不同的事，罪名和责任不会一样。下手的人、居间介绍的人、出钱的人，各自知道什么、做了什么，要一一查明。

第二，办冥婚本身，法律没有专门的禁止条款。出问题的是遗体从哪里来、怎么来。

第三，出钱的人家要不要负刑事责任、负什么责任，没有一句话可以概括，现实中也有争议。［已核：《南方周末》报道中法律界人士的看法］小说因此没有交代祁家父母的法律结局，只写了父亲去做了 11 回笔录。

## 六、落在谁身上

**被买卖的几乎都是女性。** Lo 的摘要指出，民间说法里未婚而死的忌讳男女都有，但被贩卖的遗体主要是女性。［待核：摘要］这与活人的婚姻市场是同一个结构：男方家庭出钱，女性被当作可以交付的一方。

**她的名字最先被拿走。** 小说里尚小娥失去的东西有一个顺序：先是名字（被换成“李改花”），再是年龄和来历（被写成 24 岁、病死的本分女子），再是脸（被擦上粉、涂上口红），最后才是那张纸上的一行字。祁晓云在西窑里做的事，是把这个顺序倒过来走了一遍：认出疤，想起名字，擦掉妆。

**悲伤是真的，这并不能替任何人开脱。** 白改莲的梦、她抖了 49 天的手、她怕儿子“是一个人”，小说都当作实情来写。Tan 把冥婚理解为一种安抚：安抚死者，更是安抚活人。［已核：这是他的理论解释，不是田野事实］小说想写的是这种安抚的需要怎样被人利用，以及一个本来可以用一块砖完成的心愿，怎样一步一步变成了买一个人。

**村里人为什么不问。** 第五章二叔那段话是虚构的，但它回答了一个现实中的问题：为什么这样的事可以在一个村子里办成。每一户接受过“不兴问”的人家，都有理由希望别人也不要问。

## 七、有依据的，和虚构的

| 有研究或报道依据 | 小说的虚构 |
|---|---|
| 冥婚在山西、陕北等地至今存在，并与遗体买卖犯罪相关 | 村庄、祁家、周守义、尚小娥，整个案件 |
| 未婚而死者不入祖坟的观念 | “孤坟”这个叫法 |
| 风水先生充当牵线人 | 看日子的人同时供货 |
| 红布棺材、喜宴、当日下葬（河北广宗的一例） | 把它放在山西；喜馍、长明灯、供桌等细节 |
| 可以用牌位、纸人、写了名字的砖代替遗体 | 周守义那句“横死的人怕不认假的” |
| 有人为出售遗体而杀人；有被害人被用药后险些活埋 | 尚小娥遇害的经过；小说没有写手法 |
| 遗体价格从数千到数万元不等 | 18 万、3 万这两个数 |
| 《刑法》《民法典》的相关条文 | 侦查的经过，11 回笔录，“正月里在外省抓住” |
| | 婚书的格式、死期留格后填、念婚书即“礼成”、新人的脸不兴细看 |
| | 把卯时改成寅时的那套说法 |

关于最后一项：按通行的地支六冲，与申（猴）相冲的是寅，不是卯。周守义说“卯时冲属猴的”，把事情讲反了；他临时改去的寅时，按他自己那套规矩恰恰才是犯冲的。小说没有让任何人指出这一点。

**护士能看出什么，不能看出什么。** 第三章里祁晓云摸到遗体的状况与婚书上的日子“对不上”，这是一个有经验的护士可以有的怀疑。但她判断不了死亡时间，更判断不了死因；尸体现象受温度、环境等影响很大，这些只能由法医学检验来确定。正文让她自己说了这句话。

**小票能证明什么。** 一张从衣袋里找到的超市小票，只说明有人在那个时间买过那些东西。它证明不了买的人是谁，也证明不了她后来的遭遇。小说里祁晓云是把婚书、自己的记忆、遗体的状况和小票放在一起，才形成怀疑，然后报警；查明事实是侦查机关的事。她报警时说的是“死得不对”，没有说是谁做的。

**超自然的部分。** 母亲的两个梦、最后直着往上走的烟，小说都没有给出解释。祁晓云自己的想法是“也许人在不敢信一件事的时候，耳朵是关着的，心是开着的”，后面又跟了一句“也许不是”。这是人物的不确定，不是对任何超自然现象的证明。

## 八、用符号学的眼光看

**叫她什么，就决定了能对她做什么。** 同一个人，在婚书上是“坤造李改花”，在媒人嘴里是“新人”，在买的人家是“媳妇”，在送货的人那里是一袋“她的东西”，在女儿那里是“妈”。每换一个叫法，周围的人对她的义务就换一套。这是分类在起作用：把一个人放进哪一个格子，比关于她的任何事实都更先决定别人的举动。见课程 01-05。

![一个人，七种叫法。](figs/c04-names.svg)

**一张纸怎样把事情办成。** 婚书当众念一遍，一个陌生的死者就成了祁家的媳妇。这和《用印》里盖章是同一类动作：话说出来，事情就算发生。它能成立，靠的不是纸，是在场的人都照着同一套规矩行事。周守义自己说得很明白：“规矩不是给信的人立的，是给办事立的。”见课程 02-02。

**两种记号的对质。** 婚书是约定出来的记号，它说什么，取决于写的人想让它说什么。超市小票是另一种：机器在某个时刻打出来的痕迹，它和那个时刻、那个地方有实在的连接。按皮尔士的说法，前一种靠规约，后一种是指示。小说的转折，是一张指示性的小票戳穿了一张规约性的婚书。见课程 01-03。

**谁有权改规矩。** 49 天里“一刻都错不得”的卯时，在需要的时候可以变成寅时。解释规矩的权力集中在一个人手里，而这个人同时是交易的一方。见课程 02-04。
