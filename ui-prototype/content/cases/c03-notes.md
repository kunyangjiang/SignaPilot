# 《秘本》背后的档案

> SignaPilot · Case Notes 03
> 定稿，2026 年 11 月 11 日经 PO 批准封存。含剧透。
> 标注说明：**［已核］**指这次读过原文并对照过；**［待核］**指只见到摘要、书目或二手转述；未标注的是本篇的虚构设定，或作者的概括。
> 小说写的是一个虚构的村子和一个虚构的道坛。下面讲到的研究，对象是真实的地方和真实的人，两者不能互相代替。

## 一、小说背后的田野

故事放在湖南中部，安化、新化两县交界的山区。选这里，是因为这一带的地方道教近二十年有比较扎实的田野研究。

**一个真实的参照。** 美国学者莫达夫（David J. Mozina）长期研究安化县东南部乐安镇以西一带的一支道教坛门。这一支分布在大熊山两侧的安化和新化北部，自认属正一道，用一首二十字的派诗给每一代取道名，按他的推算可以上溯到十六世纪末。当地最有名望的一位师傅，莫达夫以道名称他蒋身志（1928–2018），跟随父亲学艺，1946 年十几岁时奏职。文革中蒋家的许多书被毁，八十年代末管制放松以后，他着手搜集、重抄、整理，到二十一世纪初重建起一批至少 120 种的藏书。［已核］

**小说从这里借了什么。** 贺承安这个人物的几处骨架来自上述研究：晚年大量重抄和改写本坛的书；因为年轻一代常年在外打工、没有时间跟在师傅身边慢慢听，就把原本只在嘴上讲的要领写进书里；最要紧的那一本在抄家的年代被藏在田里、山上和不做法事的邻居家里。莫达夫还写到，蒋身志的孙子、也是他最好的徒弟，1991 年奏职后的十年里多次离村，去珠海、北京、上海、广州、深圳做工。［已核］

**没有借的。** 贺承安不是蒋身志。失明、让女儿代抄、卖书给儿子办厂、把同一箱书许给三个人，这些全是虚构。小说里的派字“承”“嗣”也是另编的，特意避开了那首真实派诗里的字。

**“给活人做道教的，给亡人做佛教的。”** 这不是为小说编的怪事。莫达夫记录的那一支坛门，就是为活人做道教的法事、为亡人做佛教的法事，有的分支还兼做当地称为“师公”的驱邪法事。［已核］香港学者谭伟伦把湘中这种以仪式为主的民间佛教称为“应教”，认为它在历史上与道教和地方的师教融合在一起。［待核：只读到摘要］

## 二、几个容易混在一起的词

小说里出现了“书”“文检”“源流”“秘旨”“牒”，它们不是一回事。

| 词 | 是什么 | 小说里对应的东西 |
|---|---|---|
| 科仪本（科文） | 一堂法事的脚本：念什么，怎么走，何时用法器 | 箱子里的大多数；刘嗣明当年抄过一套 |
| 文检 | 各种文书的样式：疏、牒、表。法事中要照着写出来，宣读，焚化 | 办丧事头一天请出来的那一本 |
| 源流 | 本坛历代师傅的名字和事迹 | 头一天请出来的另一本 |
| 秘旨 | 本坛最核心的教法，只在坛内传 | “那一本” |
| 符 | 画出来或写出来的灵文，用在具体的法事里 | 易岚不该发到网上的那两页 |
| 箓（也叫法箓、经箓） | 授给道士的名册和凭证，表明他的职位和可以调遣的神将 | 小说没有写 |
| 职牒 | 证明一个人奏过职、有道名和职位的文书 | 放进棺材的那张黄纸 |

前四类是莫达夫清点蒋身志藏书时用的分类：科文、文书样式（疏文、牒文、表文）、祖师与雷神的传记（当地叫传、出脉、源流或血本），以及秘旨。［已核］

**符与箓不同。** 符是用的，箓是授的。台湾学者谢聪辉研究福建南安和台湾的正一道坛，说明经过传度受箓的人才取得仙职、法名、职印等一整套资格；他也记录了与箓有关的一套程序，其中有“缴箓”，即把所受的箓焚化上缴，有的在生前预先举行。［已核］要强调的是，那是闽台的材料。湖南中部的坛门怎样授职、发什么文书，这次没有读到可靠的一手描述，所以小说只用了“奏职”和“牒”两个最基本的词，没有写仪式的过程。

**抄了书，不等于有了资格。** 这是全篇的支点，也是研究支持的：莫达夫写道，徒弟在奏职之前通常要手抄师傅传下的本子，以此吸收谋生所需的本事；而秘旨还要配合师傅在训练末期或奏职前后口头传授的要领才用得上。［已核］所以贺春梅抄了 31 本、听写了 11 个作业本，仍然“只晓得是哪几个字”。

**有资格，也不等于书是他的。** 法律上，这箱书是贺承安的个人财产。《民法典》规定遗产是自然人死亡时遗留的个人合法财产（第一千一百二十二条）；继承权男女平等（第一千一百二十六条）；子女同为第一顺序继承人（第一千一百二十七条）；同一顺序的继承人份额一般均等，与被继承人共同生活或尽了主要扶养义务的可以多分，继承人协商同意的也可以不均等（第一千一百三十条）；分割的办法由继承人协商（第一千一百三十二条）。［已核］徒弟不在法定继承人之列；要把财产留给继承人以外的人，需要立遗嘱（第一千一百三十三条）。贺承安生前对三个人的许诺只是平常说过的话。法律认可的口头遗嘱限于危急情况，并且要有两个以上见证人在场（第一千一百三十八条）。［已核］

反过来也一样：贺春梅抄了书、照顾了父亲，这在分配时可以作为多分的理由，却不会让那 31 本自动归她，更不会给她上坛的资格。

## 三、一坛的本事是怎么传下去的

**派字。** 用一首诗的字依次给每一代取名，是许多道教坛门和宗族共用的办法。名字一写出来，同行就知道这个人是哪一支、第几代。这是一种很经济的符号：一个字同时标出了位置和来历。

**师徒，不只是父子。** 莫达夫记录的蒋氏一门训练过九代师傅，其中有蒋家自己的人，有邻近李姓的人，也有别的姓。［已核］所以贺承安想传给儿子，儿子不学，转而收了外姓的刘嗣明，在这一带是寻常事。

**书和嘴。** 小说里贺承安说“书是死的，嘴是活的”，这句话是虚构的，意思却有依据：口传在这类传承里是正式的一环，有自己的名称。

**女儿。** 一个没有奏过职的女人替父亲抄了二十年书，这是小说的设定，这次读到的研究里没有这样的例子，也没有看到明确禁止的记载。陈承礼那句“没有奏过职的人，手是不干净的”是为人物写的看法，不是哪一坛的成规。

## 四、抄本是活的

小说题目叫“秘本”，容易让人以为那是一本从古传下来、一字不改的书。研究给出的图景正好相反。

莫达夫追查过蒋身志坛中一部秘旨的来历。书末的题记说它是十九世纪本坛一位师傅在六十多岁时编成的，依据的是他得到的一部托名吕祖的著作；现存的本子又是下一两代的另一位师傅转抄的。莫达夫进一步考证，那部被依据的著作可能与十七世纪一个主张三教合一的民间教派有关。到了二十世纪九十年代，蒋身志又为这部秘旨写了自己的“再论”。莫达夫把这种不断被有资望的师傅改写的状态称为“活的修订”。［已核］

这就是小说里那些细节的来处：

- **题记。** 抄本最后一页写明谁抄的、照谁的本子抄的、哪一年，是真实的惯例。小说的第三章和结尾都落在这一页上。
- **一箱书不是一个时代的。** 蒋身志的藏书里有晚清民国的木刻经书，也有历代师傅和他本人的抄本。贺家箱子里四种笔迹并存，由此而来。
- **改写需要资格。** 莫达夫写道，坛里的人会特意指出，不是随便哪个师傅都敢动本坛最核心的那部书。贺承安添的那些话之所以算数，是因为他是他；贺春梅知道每一句是谁添的，却无权再添一句。
- **流到市场上。** Mark Meulenbeld 研究过一部十九世纪的澧县抄本，那是道士奏职时得到的一册秘传符书，里面为《水浒传》一百零八人各配了天书。同一篇文章的一条注释提到，他用到的另一部道教抄本是 2004 年从新化的一位旧书商手里得到的。［已核］可见这类书会进入旧书市场。小说里的曹老板是虚构人物，“整箱收来再拆开卖”的做法也是为情节设定的。

需要说明：那部澧县抄本来自湘西北，与小说所在的湘中不是一地；小说里的贺家藏书与它没有任何关系，书里也没有写《水浒》。

## 五、同一箱书，四种“继承”

把小说里的四个人放在一起看，可以看到“继承”这个词底下其实压着几样不同的东西。

**物。** 纸、墨、线，一件可以买卖、可以寄存、会被虫蛀的东西。法律处理的是这一层，在没有遗嘱的情况下，它归两个子女。

**用法。** 知道在哪一堂法事的哪一步翻到哪一页，念多快，手上做什么。这一层在刘嗣明身上，靠的是二十年的上坛。

**资格。** 一个道名、一张牒、同行的承认。它不能继承，只能由师傅授予；小说里它甚至不留在世上，跟着人进了棺材。

**解释。** 知道哪一句是老本子上的，哪一句是后来添的，为什么添。这一层意外地落在了抄写的人身上。

这四样平时长在同一个人身上，所以看不出是四样。人一死，它们就散到不同的人手里，谁也凑不齐。小说的结局没有判定哪一样更“真”。最后的分法也不是法律或师门规矩自动得出的，是两个继承人、徒弟、师叔和馆员坐下来谈成、写了字据的：姐姐放弃钱，换来对书的发言权；弟弟拿钱，签字；徒弟出钱出工夫，换来抄的资格。换一家人，谈出来的完全可能是另一种结果。

**保存与使用。** 易岚说到了馆里的书“大多数时候就在那里放着”，贺承安说“书要用，越用越在”。两句都对。图书馆能让纸多活几百年，却不能让它继续被念出来；留在坛里的书会继续被用，也会继续被翻烂、被改写。小说把最老、已经不能再用的 18 本送去寄存，把仍在使用的留在村里，是让这两种逻辑各管一段。

**公开的边界。** 易岚把别人的符和口诀发到公众号，随后被人盗印出售，这件事是虚构的，但它指向一个真实的难题：研究者能看到的，不等于可以公开的；判断哪一页不能公开，往往只有仍在使用它的人才做得了。莫达夫在文中也写到，他讨论的那部秘旨“只在坛内传授，不应与外人分享”，而他是在师傅允许之下研究它的。［已核］见课程 09-04。

**用符号学的话说。** 一本科仪书同时是好几种符号。对上坛的人，它是脚本，是指令；对同行，题记和派字是一个人身份的标记；对旧书商，年款和品相是价格的标记；对馆员，它是一个时代的证据。同一件东西，在不同的规则里被读成不同的东西，见课程 01-01、02-01。而谁有权决定它该被怎样读，是课程 02-04 的问题。

## 六、史实与虚构

| 有研究依据 | 小说的虚构 |
|---|---|
| 安化、新化一带有世代相传的道教坛门，用派诗取道名 | 贺家、那个没有写出名字的村子、派字“承”“嗣”，所有人物 |
| 同一坛门为活人做道教法事、为亡人做佛教法事 | 丧事三天的安排，道场上做了什么 |
| 藏书由刻本经书和历代抄本组成，分科文、文书样式、传记、秘旨 | 124 本的数目，各堆的本数 |
| 徒弟奏职前手抄师傅的本子；师傅会重抄，也会改写 | 女儿代抄 31 本，落父亲的名字 |
| 文革中交出刻本经书和一部分科本，把秘旨藏在田里、山上和邻居家 | 藏在蜂桶里这个细节 |
| 年轻师傅外出打工，口传难以为继，师傅把口诀写进书里 | 叫了徒弟三回，以及那场争吵 |
| 这类抄本会经旧书商流入市场 | 曹老板，18 万的开价，50 块一本的“搭头” |
| 子女平等继承，份额可协商 | 字据的内容，图书馆“须全体继承人签字”的做法 |

## 七、为了写小说而简化或编造的地方

- **丧事的仪式一概没有写具体做法。** 这一带为亡人做的是哪些法事、各有什么名目，这次没有读到足够可靠的描述，所以正文只写了“做了三天”“夜里那一堂”“最后一堂”。“开路”“安胎”“收惊”“还愿”是这类法事常见的通称，小说没有描写它们的内容。
- **“牒随人走”是贺承安个人的心愿。** 小说没有把它写成当地的规矩。道士身后如何处置受职文书，各地不同，湘中的做法这次没有查到；第二节提到的“缴箓”是福建、台湾的材料，不能拿来证明湖南。
- **“秘旨没有到手就带不了徒弟”**是为情节做的简化。研究只说明秘旨讲的是每位师傅都必须掌握的根本方法，并没有说缺了它在程序上就不能授徒。
- **龙家孩子的事是虚构的。** 小说没有说贺承安的法事是否灵验，只写了他相信，也写了他记得有一回没有留住人。
- **女儿替父亲抄了二十年书**是虚构的设定，这次读到的研究里没有对应的例子。
- **图书馆的寄存、征集奖励、著录方式，以及“须全体继承人签字”**，是为这家虚构的县图书馆设定的做法，没有对应哪一家馆的实际制度；一家馆收不收、怎么收，取决于它自己的规定。私人收藏的抄本并不因为年代久就自动成为国家所有的文物，小说里也没有人这样主张。
- **方言只取了一点口气**（讲、晓得、伢子、崽、娭毑），没有按安化或新化的实际方言去写。
