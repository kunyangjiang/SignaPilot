## 一、先说清楚

小说里的长河面馆、拱宸桥那间门面、六安的面摊，以及骆冬青、许长河、阿葛、许乐、汪医生、卢老师、郝老师，都是虚构的。骆冬青得的病是真实存在的：原发性进行性失语（primary progressive aphasia，PPA），语义变异型（semantic variant，svPPA）。

读这篇小说时，请记住五件事：

1. **雅各布森不是临床分类。**他 1956 年那篇文章讲的是语言学上的两条轴，用当时的失语症文献作材料。今天的医生不用“相似性障碍”“邻接性障碍”来诊断病人。小说借这两条轴来写一个家，不是说 svPPA 就等于他说的哪一型。
2. **私人符号不是临床治疗。**敲三下、画葱、钥匙、照片，是这对夫妻自己的东西。它们有用的时候，靠的是三十多年的共同生活；它们失灵，也不说明言语治疗没用。
3. **不能拿小说来诊断。**家里有人叫不出东西的名字，原因可能有很多种。要去神经内科或记忆门诊，由医生做检查，不要对着小说或网上的描述自己下结论。小说里许乐在网上查到阿尔茨海默病，也是错的。
4. **同一个亚型，病程也因人而异。**骆冬青先丢什么、后丢什么、几年走到哪一步，都只是一个人的样子。医生在小说里不肯说“几年”，现实中也说不准。
5. **失语不等于失去这个人。**骆冬青到最后也有自己的脾气、喜好和不肯说出来的意思。小说的悲剧不在她“没有了”，在于她还在，别人却不再等她说完。

## 二、雅各布森 1956：两种失语，两条轴

罗曼·雅各布森（Roman Jakobson）的《语言的两个方面与两类失语症》（*Two Aspects of Language and Two Types of Aphasic Disturbances*）收在他和莫里斯·哈勒合著的《语言基础》（*Fundamentals of Language*，海牙：Mouton，1956）里。［已核］

他的出发点是：说话总要同时做两件事。一是**选择**，从一组可以互相替换的词里挑一个；二是**组合**，把挑出来的词按次序接成句子、放进上下文。选择靠的是词与词之间的**相似**，组合靠的是**邻接**。［已核］

失语症在他看来，正好可以分成两类，各坏一边：

| | 相似性障碍（similarity disorder） | 邻接性障碍（contiguity disorder） |
|---|---|---|
| 坏掉的能力 | 选择与替换 | 组合与上下文 |
| 还剩下的 | 上下文、连接词、语法框架 | 单个的词，尤其是名词 |
| 常见的说法 | 用“东西”“那个”代替名词；按用途、按位置称呼东西 | 电报式的句子，词序混乱 |
| 偏向的修辞 | 转喻（借邻接） | 隐喻式的近似（借相似） |

文中几个例子，小说直接用过：［已核］

- 相似性障碍的病人，上下文是“不可缺少、起决定作用的”。给他半句话，他能接下去；让他自己开头，就很难。他说不出“下雨了”，除非他亲眼看见在下雨。小说第四章里，许长河问“明天会不会下雨”，骆冬青答不上来；早上推开窗看见地是湿的，她自己说“下雨了”。
- 戈尔德斯坦（Goldstein）的一位病人从不单说“刀”，按用途和场合分别叫它削铅笔的、削苹果的、切面包的。骆冬青把剪刀叫“剪鱼的”，店里另一把是“剪胶带的”。
- 这类病人做不了“A 就是 B”这种说明。问他“单身汉是什么”，他答不上来，在日常对话里却能用对这个词。雅各布森把这叫作元语言能力的丧失。骆冬青能把“骆驼”复述得一字不差，问她骆驼是什么，她说“骆驼就是骆驼”。
- 他还提到，这样的病人难以从图像、指示转到对应的语言符号。这一点和皮尔士的符号三分直接相连。

这两类之分，是雅各布森从失语症材料里推出来的语言学概括。他自己也说，病人那种“准隐喻”式的近似说法不是有意的修辞，跟诗里的隐喻不同。［已核］他用的病例出自杰克逊（Hughlings Jackson）、黑德（Head）、戈尔德斯坦等人此前几十年的记录［已核］，多是中风、外伤一类造成的失语，不是 PPA［待核］。

## 三、选择、替换、组合、邻接：在面馆里

![同一把剪刀放在两条轴上。竖轴是选择与替换：把剪刀印在卡片上，问“这个叫什么”，或者说“像勺子那个”，都要她在一组相似的词里挑，她挑不出来。横轴是组合与邻接：灶台、挂钩、剪刀、姜袋，一样挨着一样，她一伸手就拿到了。](figs/c15-axes.svg)

小说里这两条轴不是用来讨论的，是用来让人物做事的：

- **卡片练习**（第四章）走的是替换轴。一张白底卡片上印一把剪刀，没有挂在哪里，也没有在剪什么。她卡住了。翻到背面念出字来，她说：“我念的，不是我想起来的。”
- **熬汤**走的是组合轴。灶台左边的挂钩、姜袋、葱结，一样挨着一样，她一个早上用了七八回剪刀，一回也没卡住。
- 许长河学会说“灶台旁边那个”，不说“像勺子那个”。这是两条轴最朴素的用法。
- 他也学会了替她起头。这本来是在邻接轴上帮她，起着起着就变成替她收尾，又变成替她做决定。小说的悲剧，就是从这一点一点滑过去开始的。
- **沈家门**（第六章）把这一层推到最远：在码头、鱼摊、渔船旁边，她的词一个接一个回来；离开那里，就又没了。这是小说的放大处理。有研究讨论过个人经历和日常使用对 svPPA 病人保留词义的作用，见第八节。

## 四、隐喻与转喻：谁在用哪一种

骆冬青的说法大多是**转喻**：用东西的用途、位置、旁边的东西来代替它。她叫冰柜“冻的那个箱子”，叫漏勺“捞的”，叫女儿“北京”那一头，叫丈夫“端面的”。“端面的”原本是职业，后来是他的名字，到最后变成任何一个端饭来的人。

许长河更爱用**隐喻**。他对女儿说：“你妈现在像一本旧书，字一页一页褪掉了。”骆冬青只回了一句：“我不是书。”这个比方说得越准，越是把她当成一样被人拿在手里、看着褪色的东西。小说让她拒绝这个比方，也是在拒绝这种看法。

两人的误会也常落在这两种读法之间。签字前一晚，碗里撒着葱花，纸上画着划了斜杠的葱。许乐顺着邻接把它读成“不要葱”，许长河选了离面近的那个意思。可它在两人的约定里是“不要”。

## 五、失语症与 PPA

**失语症**（aphasia）：美国言语语言听力协会（ASHA）的定义是，脑损伤造成的获得性神经源性语言障碍，涉及说、听、读、写四个方面。它不同于**构音障碍**（dysarthria，肌肉控制问题，说话含糊）和**言语失用**（apraxia of speech，说话的运动计划出问题）。这两种是运动性的言语障碍，可能和失语同时出现，要靠专门的运动言语检查来区分。［已核］

**原发性进行性失语**：语言能力因神经退行性疾病而逐渐变差，起病时语言问题最突出。诊断标准要求，在疾病早期，日常生活中主要是依赖语言的活动受影响，其他认知能力相对保留。“相对保留”说的是早期，不是说以后一直如此。［已核］

PPA 是一种临床综合征，以进行性的语言损害为主要早期表现，可以由不同的神经退行性病理引起，不能整体归入某一种病：svPPA 常见 FTLD-TDP 病理；nfvPPA 常见 tau 等 FTLD 病理；lvPPA 与阿尔茨海默病病理的关联较强（见第六节）。［已核］ASHA 的科普页面是在额颞叶痴呆的框架下介绍 PPA 的［已核］，本文不沿用“PPA 都属于额颞叶痴呆”的说法。按 ASHA 的介绍，PPA 较少见，多在四五十岁到六十多岁之间起病；目前没有治愈的办法，也没有直接针对病因的治疗。［已核］

2011 年戈尔诺-滕皮尼（Gorno-Tempini）等人发表的国际共识把 PPA 分为三个亚型，即本文第六节。诊断的前提是排除其他原因，比如早期就有显著的情景记忆或视空间障碍，或者以行为问题为首发主诉。［已核］这个标准主要面向早期病人，有些人的表现落不进任何一型，归为“不能分类的 PPA”。

## 六、三个亚型

以下依据 Gorno-Tempini 等（2011），*Neurology* 76(11)：1006–1014，PMC3059138。［已核］

| | 语义变异型（svPPA） | 非流利/语法缺失型（nfvPPA） | 少词型（lvPPA） |
|---|---|---|---|
| 核心特征 | 命名困难，**并且**单词理解受损（两项都要有） | 语法缺失，和/或说话费力、断断续续（常伴言语失用） | 自发言语和命名中找词困难；句子复述受损 |
| 支持特征 | 物品知识受损（先是少见、不熟悉的东西）；表层失读/失写；复述保留；语法和发音保留 | 复杂句理解差；单词理解和物品知识保留 | 语音错误；单词理解、物品知识、发音保留，没有明显语法缺失 |
| 影像（典型） | 前颞叶萎缩，常以左侧为主 | 左侧额叶后部—岛叶 | 左侧颞顶交界 |
| 常见病理 | 常见 FTLD-TDP | 常见 tau 等 FTLD 病理 | 与阿尔茨海默病病理关联较强 |

两点提醒：一是临床亚型和病理之间没有一一对应，表中“常见”“关联较强”都不是“一定”；二是小说只写 svPPA，没有把另外两型的特征混进来。骆冬青说话一直流利，语法和发音没坏，复述也保留得好。她丢的是词的意思。

**svPPA 往后会怎样**：词义的丢失会扩展到物品和概念本身，不再限于说话，看图、摸东西也一样认不出。萎缩可能扩展到另一侧颞叶和额叶内侧，带来行为改变：变得刻板、饮食偏好固定、对别人的情绪反应变少、冷漠或失控；部分病人会认不出人脸。［待核：只见摘录］小说第七章以后的定胜糕、六点十分开门、阿葛哭时她只说“汤”，第十章的苏打饼干，写的都是这一类变化。这些表现每个人不同，也不是每个人都有。

**中文的读写**：svPPA 在拼音文字里常见“表层失读”，即按拼写规则读不规则的词。中文没有字母与读音的规则对应，有病例报告描述病人“只读半边”（读成声旁），也有研究认为中文 svPPA 更像别的失读类型，这个问题还在讨论，证据都来自很小的病例系列。［待核：只见摘录］小说里“鳝”读成“善”、“蜗”读成“窝”，用的是“读半边”这一种描写，不代表中文病人都这样。

## 七、语言、认知、沟通是三件事

- **语言**坏了，不等于**认知**全坏了。疾病早期，其他认知能力相对保留：骆冬青早期记事、认路、算账、画钟都好，汪医生特意对许乐说“不是先忘事”。
- 认知也不是全都保留。svPPA 往后会影响物品知识和行为，第七章以后，她的世界本身在变窄。
- **沟通**又是另一件事。ASHA 的 AAC 页面写道：认知受损并不妨碍沟通。［已核］推开杯子、踢开鞋、摔一下漏勺、在中介那张纸上画一根葱，都是沟通。郝老师说：“看她在说什么。”

小说的冲突就在这里：许长河把汪医生说的病程（语言与认知）当成了骆冬青不再能沟通的理由。医学上的话本身没有错，第十一章里他自己也承认“这些话都没有错”。错在拿这些话去替她回答。

## 八、多模态沟通、AAC 与沟通伙伴

**AAC**（辅助与替代沟通）：分为不借助工具的（手势、表情、身体动作）和借助工具的；后者又分低技术（沟通本、照片、图卡）和高技术（平板、语音输出设备）。［已核］

ASHA 关于 PPA 和 AAC 的几条建议，小说都写进去了：［已核］

- 言语治疗师要先了解病人自己最在乎跟谁沟通、沟通什么（卢老师的第一个问题）。
- 要趁早引入那些“今天也许用不上，以后会用上”的工具，包括把病人的话录下来以后用（卢老师的平板录音）。
- 沟通伙伴要给对方时间，不要替他说完；提供选项；有决定要做时，让病人参与（卢老师那张清单）。
- 沟通伙伴常常只问是非题，自己主导谈话，所以伙伴训练很重要。
- 进行性疾病里，AAC 系统要灵活、能随时调整；到了后期，目标是尽量让病人表达自己的需要和决定，能多久就多久（郝老师从照片换成实物）。

**AAC 不是治愈。**它不能让病停下，只能多开一条路。小说里沟通本被扔进垃圾桶，又被捡回来、放上柜顶，不是说沟通本没用，而是说这条路也会随着病变窄。

**重新学词**：有研究让 svPPA 病人反复练习跟自己生活有关的词，有一部分人练过的词能维持一段时间，没练的、用不着的就继续丢失。［待核：只见摘录］卢老师那句“天天用得着的词，留得久一点”来自这一类研究的大意，具体效果因人而异。

**个人经历与词义**：斯诺登（Snowden）、格里菲思（Griffiths）和尼尔里（Neary）1994 年描述过一位 svPPA 病人，她保留的多是和自己当下生活有关的词，下定义时也带着很强的个人经历色彩。作者因此认为，个人经历有助于保住词义。这个看法后来有争议，有研究没有发现个人参与带来的普遍好处。［待核：只见摘录］小说里“地方能把词留住”是许长河自己的体会。他在第十章想不清，是病走到了这一步，还是离开杭州把她推到了这一步，没有人能替他分清，这篇 Notes 也不能。

## 九、私人符号系统：一份符号学账单

![七个私人符号的来路和去向。前三个都在关键时刻被许长河读成了对他方便的意思；最后一个，摸左耳垂，没有人知道是什么意思。](figs/c15-signs.svg)

这套符号有几个特点：

1. **共同创造，每一个都有生活来历。**敲三下来自他的左耳和出菜口，画葱来自阿葛的鸡爪字，照片来自婚后第二天。没有一个是从书上抄来的图标，卢老师也说“用你们家自己的东西”。
2. **意义靠共同经验建立，也随场合改变。**敲三下在锅沿、窗框、桌面上各有意思，许长河“听声音就知道是哪一种”。这是索绪尔所说的意义来自差异：同一个动作，在系统里的位置不同，意思就不同。
3. **她修改、拒绝、重新定义。**她把“过来”和“端走”分开；把敲三下改成“我来”；撕掉“上厕所”那张图标；把“睡觉”改成“出去打牌”；把卢老师教的大拇指改成“你又装好人”。“我的本子”是她对这套系统主权的声明。
4. **他误读，有时出于自己的期待。**捏脸被当成牙疼，是无心的。钥匙被当成症状，葱被当成“画着玩”，敲三下被听成“端走”，都是在两个意思里选了对自己方便的那一个。第二章里两人有过约定：“你不许替我说。”
5. **新符号没能接替旧的。**捏脸和旧词一起松掉了。符号要靠底下的意义撑着。svPPA 坏的正是这层意义，所以手势、照片、实物并不总能绕开病。照片从“我们俩”变成“以前”，又变成“海”“蓝的”“人”，是这一点最清楚的例子。
6. **有的意思只属于她。**摸左耳垂，读者可以去想那对 1995 年卖掉的金耳环，也可以不想，小说不给答案。第七章卢老师那句“家属不一定懂，也不一定要懂”，是这套系统里最难的一条规矩。
7. **到最后不再稳定运作。**最后一章，敲三下还在，可是过来、端走、我来，还是别的，已经没有人能确定。

从 01-06 文化符号学的角度看，这是一个只有两个人的“小文化”。从 02-04 的角度看，小说问的是：在这个小文化里，谁有权解释一个符号？许长河一直以为是他，因为他是会说话的那一个。

## 十、医学事实与小说虚构

| 小说里的 | 依据或处理 |
|---|---|
| 诊断过程：神经内科、测验、磁共振、抽血，排除其他原因 | 符合 PPA 诊断的一般程序；细节是简化的 |
| 命名差、单词理解差（第二章：听诊器指成雨伞，不懂“吝啬”“砚台”，常用的“小气”还懂）、复述保留、语法保留 | svPPA 核心与支持特征［已核］ |
| 常用的、自己用得着的东西（碗、锚、剪鱼的）保留得久 | 物品知识先丢少见、不熟悉的［已核］；个人相关性的作用有争议［待核：只见摘录］ |

| 刻板、饮食固定、冷漠、认人困难 | svPPA 进展中可能出现，因人而异［待核：只见摘录］ |
| 汪医生不说“几年” | PPA 的进展速度个体差异很大，不应给出固定年限 |
| 汪医生建议“趁现在您自己来定” | 与 ASHA 强调的让病人参与决定一致；“提前规划”的具体法律程序小说没有写 |
| 卢老师的录音、沟通本、伙伴策略 | ASHA PPA 与 AAC 页面［已核］ |
| 沈家门码头上词“回来了” | 小说的放大处理，不是临床观察 |
| 搬家加速了丧失 | 小说没有下这个结论，许长河自己也分不清 |
