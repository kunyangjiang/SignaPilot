## 一、最早的一批“文书”：三官手书

道教和文书的关系，可以从东汉末年汉中的天师道（五斗米道）说起。

《三国志·魏书·张鲁传》裴松之注引《典略》，记了天师道给病人祈祷的办法：把病人的姓名写下来，写上认罪的意思，一式三份，一份放在山上，交给天；一份埋进地里，交给地；一份沉进水里，交给水。这叫“三官手书”。病人家里要出五斗米，所以这一派被叫作“五斗米师”。［已核：维基文库《三国志》卷八］黎志添（Lai Chi-tim）等学者把这段记载看作早期天师道宗教教义最早的史料。［待核：只见摘录］

![三官手书：一份文书写三份，分别交给天、地、水。](figs/c12-sanguan.svg)

这一段里，后来道教文书的几个要素已经都有了：写明是哪一个人；说明为什么写；有明确的收件者；有一种把文字送到看不见的地方去的办法。斯坦福哲学百科的“Religious Daoism”条目也说，天师道的社群用户籍和个人名册来管理成员，治病时向天、地、水三官递交文书，陈述过失、忏悔、请求帮助，病被看作道德过失的结果，而不是鬼怪作祟。［已核：SEP，Pregadio］

## 二、章、表、牒：不是同一种纸

**“章表”是一个总称。** 道教斋醮仪式里呈给神明的文书，统称“章表”，包括奏章、青词、表文等。［已核：二手，道教文化中心“章表”条］明代周思得的《上清灵宝济度大成金书》列出了十六种文书格式，其中有奏、启、申、牒、关、状、疏、章、表、笺。［已核：二手，同上］光看这张名单就知道，道教仪式文书的分类，和人间衙门的公文分类非常接近。

**它们模仿的是人间的公文。** 道教文化中心的条目引《灵宝玉鉴》，说仪式文书仿照的是人间官府之间往来的文书；又引南宋吕元素《道门定制》的序，说“表状文移”之类的格式，很多是仿照人间的礼仪添设出来的。［已核：二手。《道门定制》序文的原文这次没有读到］《道门定制》收在《正统道藏》里，是一部专讲斋醮文书制度和格式的书。

**章和表，出现的时代不同。** 上章（向天曹呈递章文）是很早的做法。有学者认为，上章仪式里“出官”“拜章”这些环节，起源于东汉汉中的天师道，东晋末到刘宋初被上清派改编，收进《太真科》，后来的《赤松子章历》又引用了这些内容。［待核：只见摘录，吕鹏志的研究］《赤松子章历》本身的成书年代，学界也有争论，从六朝末到唐代都有人主张。［待核：只见摘录，据王宗昱对各家说法的梳理］南北朝时陆修静就说当时的斋仪上千种、章文上万通；而专门的“进表”仪式，是宋元以后才形成的。［已核：二手，道教文化中心“进表科仪”条］

**进表的程序。** 据道教文化中心的介绍，进表科仪大体分启坛、请圣、拜表三段：高功（主持仪式的道士）在拜表时请“司表仙官”递送表文，存想自己的元神护送表文上天，步罡踏斗，最后封表、送表。各派各地做法略有不同，框架大体一致。［已核：二手］

**牒、关、状。** 大体说来，章、表是往上呈的，牒、关多用于同级或向下的通知、移送，状是陈述事情的报告；这和明清衙门里上行文、平行文、下行文的区分相似。［待核］但这种对应只是粗略的。同一个名称，在不同时代、不同道派、不同地方，用法并不一样，宋元的格式不能直接套到汉代，也不能套到今天各地的科仪本上。

**“某”字。** 斋醮的科书里，很多文书是现成的格式，地名、人名的位置空着，写一个“某”字，用的时候换成具体的名字。［待核］小说里孔道士的那部科书，就是照这个意思写的；书里的句子是作者模仿的，不是从哪部真实科书里抄来的。

**明代的箓和道士的资格。** “受箓”是道士正式取得仪式资格和神职身份的程序：箓上写明受箓人的名字、法名和他可以召请的神将。［待核］科书只是格式手册，谁都可以抄、可以继承；箓却是给某一个人的。所以小说里写明，孔一清本人在龙虎山受过箓，科书才是祖父传下来的。从南宋以后，各个符箓派别大多归到正一派之下，授箓的权力集中在龙虎山的张天师；明代仍由正一真人颁授。［待核：只见摘录，香港中文大学《道教研究学报》相关论文的摘录］明代朝廷另有一套管理僧道的制度，由礼部和僧录司、道录司发度牒；明律对僧道娶妻有禁令，可是有家室、住在家里替乡邻做法事的“火居道士”，在南方一直很常见。［待核］这几条之间怎样落实到一个江南小镇的道士身上，各地情况差别很大，小说没有去写，也不该拿今天的宗教管理规定去推想明代。

## 三、阴间为什么像一个衙门

**汉代墓里的“告地书”。** 西汉初年的一些墓里，出土过一种随葬文书，叫告地书或告地策，例如湖南长沙马王堆 3 号墓、湖北荆州谢家桥 1 号墓（年代为吕后五年，公元前 183 年）。它们模仿当时的通行证件“传”和“过所”，用官府公文的口气，向地下的官吏报告死者的户籍和财产，请求“谒告地下丞以从事”。［已核：二手，维基百科“告地书”条］也就是说，早在道教成形之前，就有人把死后的世界想象成一个要登记户籍、要凭文书放行的地方。

**从官文书到烧纸。** 告地书是随葬的，放进墓里；天师道的三官手书，一份上山、一份入土、一份沉水；后来的斋醮把章表焚化送出。［已核：二手，见前文］民间给亡人烧纸钱、纸衣，再往后又有中元节“烧包袱”：把冥钱包成一包，封皮上写明亡人的称谓、名字、包数、烧包人和日期，开头常写“中元之期”。［已核：二手，网络民俗文章，可靠性有限］这几种做法之间的影响关系，这次没有找到可靠的研究，不能说哪一种是从哪一种来的。

**包袱封皮的年代。** 烧包袱、写封皮的习俗，今天在华南、华中和江南都有记载，各地写法不一。这个习俗从哪个朝代开始，能不能上推到明代万历年间的江南，这次没有找到史料，只见到网络文章说起源朝代不明。［待核］小说让万历年间的胡记纸扎铺写封皮，是一个有意的时代假设，不是史实。

**生死簿。** SEP 的条目说，在道教的宇宙观里，阴间的官吏掌管“生死簿”；也有让亡者脱离阴间、升入仙界的仪式，比如道士下到地狱去超拔亡魂的“炼度”。［已核：SEP］

**十王和地狱的审判。** 唐宋以后，受佛教影响的“十王”信仰，把死后的审判想象成一级一级的衙门过堂，每一殿有判官、有簿籍。［待核：Teiser 的研究］

**志怪里的冥吏。** 六朝到唐宋的志怪笔记里，有大量“死而复生”的故事：一个人死了，被冥吏带到阴间，经历一番审问，又被放回来，回来以后讲阴间的见闻。Robert Ford Campany 的《早期中古中国的死而复生叙事》是研究这一类故事最重要的论文之一。［待核：只见书目，Journal of Chinese Religions 18 (1990): 91–125］这一类故事里，常有冥吏拿错了人的情节，因为同名、同姓或者差一个字。这一点作者凭的是以前的阅读，这次没有找到可以直接引用的篇目，所以不举具体的例子。［待核］

**崔判官添的两笔。** 小说读者最熟悉的阴间文书故事，大概是《西游记》第十一回：崔判官看见唐太宗的寿数写着“贞观一十三年”，“急取浓墨大笔，将「一」字上添了两画”，太宗就多了二十年阳寿。［已核：维基文库《西游记》第十一回］《误投》的设定正好反过来：书里的阴司，最怕的就是有人在公文上添一笔。所以姚福顺想到添一个“新”字，马上就被讲清楚了后果；他最后用的不是改字，而是让纸换一个主人。另外，《西游记》的世德堂本刊行于万历二十年（1592）前后，小说故事发生在三年后，书里的人物没有提到它。［待核］

## 四、哪些是史料，哪些是小说

| 小说里的 | 来源 | 说明 |
| --- | --- | --- |
| 阴间的文书模仿人间公文 | 史料 | 告地书、斋醮文书的格式都有这个特点 |
| 写在纸上、烧过去，文书就送到 | 史料中的仪式做法 | 送表、焚表是仪式的一部分；小说把它写成真的能送到，这是小说的设定，不是对仪式效果的判断 |
| 道士受过箓，上的章才有分量 | 有史料依据的观念 | 授箓决定道士的资格和神职，参见课程 05-07；“有箓的先投”“缓勾”是小说的发明 |
| 中元节烧包袱、写封皮 | 民俗 | 江南、岭南等地都有；具体从哪个朝代开始这样写封皮，这次没有核 ［待核］ |
| 簿房、投房、追班、换簿 | 虚构 | 小说自己的阴司机构 |
| 盖了到就是你的牒；下不议上 | 虚构 | 借用了衙门收文登记的习惯，规则本身是小说的 |
| 阴间没有新纸 | 虚构 | 小说的发明 |
| 私纸、公纸、无主纸 | 虚构 | 烧给某个亡人的是私纸，写不成公文；烧给城隍司本衙门的表文是公纸；无主纸可以拿来写公文，但它日后可能被补签认领 |
| 补签、签找包 | 虚构 | 借用了“封皮写明收件人”的民俗，规则本身是小说的 |
| 委：盖到之前，班头可以把牒委给别班差役 | 虚构 | 借用了衙门“委差”的说法，规则是小说的 |
| 孔道士本人受箓，科书是祖传的 | 虚构人物，有史料背景 | 明代授箓集中在龙虎山［待核：只见摘录］ |
| 冯阿四案、程家、上下河口 | 虚构 | 清浦县是虚构的县 |

小说里的阴司，是作者用历史上的文书想象搭起来的一套规矩，不是任何道派的教义，也不代表真实的斋醮仪式会产生书中写的效果。

## 五、一张纸凭什么生效

《误投》里，一张牒要能勾人，要同时满足三件事：

![小说里的一张牒：从簿房到差役手里，在哪几个地方可以出错，又在哪几个地方可以被纠正。](figs/c12-route.svg)

- **印。** 牒要盖簿房的印。印说明是谁签发的，有没有权签发。这是权威。
- **到。** 牒要被收件的人盖上“到”字。盖了到，收件的人就承认了这张牒是给自己的，从此对它负责。这是承认。
- **纸。** 牒要写在不属于任何私人的纸上：衙门自己的公纸，或者眼下没有主人的纸。这一条最荒唐，可也最有意思：一张纸能不能代表“公家”，取决于这张纸本身属于谁。簿房贪方便用了无主纸，就留下了一个日后可能被认领的口子。

哲学家奥斯汀讨论过，“我宣布”“我任命”这一类话，要在合适的人、按合适的程序、在合适的场合说出来，才算数。［待核：J. L. Austin, *How to Do Things with Words*, 1962］小说里的三条，几乎是这个说法的一个戏剧版本：印对应“合适的人”，到对应“对方接受”，纸则是一个被大家忘掉的物质前提。

这也是这篇小说想问的问题。一张形式正确、内容错误的牒，责任在谁？簿房说，簿房只认簿；投房说，投房只认抬头；差役说，牒上写谁拿谁。每一个环节都只对自己那一格负责，每一格都说得通。姚福顺最后说的“到字是我盖的”，意思是：在这一串环节里，他承认有一格是他的。

还有一个细节。救下胡二姑的，不是道士的章，是一个不识字的挑夫写的三个字。道士有箓，那道章在阴间先投；可是章上的地名写得太对了，落了空。补签没有箓，也不用走投房，它的分量只来自一件事：只有儿子能说清“先父”是谁。符号的权威不只来自签发它的人，也来自谁有资格解释它，这正是课程 02-04 讨论的问题。

## 六、参考资料

**这次读过的**

- Fabrizio Pregadio, “Religious Daoism,” *Stanford Encyclopedia of Philosophy*（2016 年首发，2020 年修订）。读了天师道、灵宝与上清、仪式与文书、阴间与炼度等节。
- 《三国志·魏书·张鲁传》裴松之注引《典略》，维基文库本。
- 《西游记》第十一回，维基文库本。

**读的是百科或网站的转述**

- 道教文化中心资料库，“章表”条、“进表科仪”条。其中引到的《灵宝玉鉴》《上清灵宝济度大成金书》《道门定制》序、《陆先生道门科略》，原文都没有读。
- 维基百科，“告地书”条。

**只见摘录或书目**

- Lai Chi-tim（黎志添）关于早期天师道的章节，Project MUSE 上的摘录。
- 吕鹏志关于出官、拜章源流的研究；王宗昱关于《赤松子章历》成书年代的综述。只见搜索结果中的摘录。
- 吕元素，《道门定制》，收入《正统道藏》。这次没有读到正文。

**凭以前的阅读，这次没有核对的**
